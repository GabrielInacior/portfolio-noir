FormataAI

Fala virando texto formatado, por IA

Código no GitHub

App mobile de TCC que transforma fala informal em e-mail, mensagem, orçamento ou receita prontos. Grava a voz, transcreve com Whisper e formata com GPT-4o-mini. Pensado para quem tem menos fluência digital.

  • Flutter
  • Dart
  • Node.js
  • Prisma
  • PostgreSQL
  • OpenAI

O app

FormataAI transforma uma fala informal em e-mail, mensagem, orcamento ou receita prontos para usar. Foi o meu trabalho de conclusao de curso.

Voz vira texto

Voce grava a voz, o app transcreve com o Whisper e formata com o GPT-4o-mini, entregando um texto estruturado e limpo.

Pensado para incluir

Feito para quem tem menos fluencia digital: em vez de digitar e formatar, a pessoa so fala e recebe o texto pronto.

Design de prompt

O segredo esta no desenho dos prompts e na gestao de contexto, para a saida sair sempre no formato certo.

Como foi feito

App em Flutter, backend Node com Prisma e PostgreSQL, OpenAI Whisper e GPT, armazenamento em AWS S3 e notificacoes push.
