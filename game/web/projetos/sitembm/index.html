MBM Site

Blog e landing pages com CMS completo

AcessarRepositório privado

Plataforma de landing pages e blog institucional para empresa de telecom, com CMS admin, newsletter, analytics e SEO dinâmico. Backend com auth JWT + 2FA, roles e upload para S3.

  • Nuxt 4
  • Vue 3
  • TypeScript
  • Node.js
  • PostgreSQL
  • AWS S3

A plataforma

MBM Site e uma plataforma de landing pages e blog institucional para uma empresa de telecom, com um painel administrativo completo.

CMS proprio

Um CMS feito do zero deixa a equipe criar e editar paginas e posts, com newsletter e analytics integrados.

SEO dinamico

Cada pagina gera seu proprio SEO de forma dinamica, para ranquear melhor nas buscas.

Seguranca

Login com JWT e duas etapas, papeis de acesso e upload de arquivos para a AWS S3.

Como foi feito

Nuxt 4 e Vue 3 no front, Node no back, PostgreSQL e armazenamento em AWS S3.
