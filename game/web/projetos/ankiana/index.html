AnkiAna

Flashcards com IA e repetição espaçada

Codigo no GitHub

App mobile de estudos que transforma tema, texto ou PDF em dezenas de flashcards com IA, usando repetição espaçada (SM-2). Interface Material 3 moderna e acessível.

  • Flutter
  • Dart
  • OpenAI
  • Material 3

O app

AnkiAna vira um tema, um texto ou um PDF em dezenas de flashcards com IA, para voce estudar sem montar os cartoes na mao.

Repeticao espacada

Usa repeticao espacada, o metodo SM-2, para mostrar cada cartao na hora certa de lembrar e fixar melhor o conteudo.

Interface moderna

Visual Material 3 moderno e acessivel, pensado para estudar no celular com conforto.

Como foi feito

App em Flutter com Dart, integracao com IA para gerar os cartoes e design Material 3.
