InacioCyber

Agente de pentest autônomo, 100% local

Repositório privado

Agente de segurança que roda inteiro na sua máquina: você conversa num chat estética terminal, define um alvo autorizado e um modelo local encadeia ferramentas reais de recon, varredura e auditoria de código, terminando com um relatório. Só para uso autorizado.

  • Python
  • Ollama
  • Docker
  • Pentest

A ferramenta

InacioCyber é um agente de segurança que roda inteiro na sua máquina. Você conversa num chat com estética de terminal e define um alvo que você possui ou tem autorização para testar.

Agente que encadeia ferramentas

Um modelo de IA local, via Ollama, decide e encadeia ferramentas de reconhecimento, varredura e auditoria de código, e no fim escreve um relatório em markdown.

Tudo local

Roda em containers Docker na sua maquina. Nada sai para fora, so as requisicoes que o proprio agente faz contra o alvo autorizado.

Uso responsável

Feito apenas para uso autorizado. Cada sessão exige uma confirmação por escrito de que você tem permissão para testar aquele alvo, e tudo fica auditado.

App de verdade

Tem app desktop proprio em Electron, chat em tempo real por WebSocket, historico de sessoes e barra de metricas de maquina.

Como foi feito

Python no agente e nas ferramentas, modelo local via Ollama, Docker para tudo, Postgres para auditoria e Electron no desktop.
