OrbixHub

SaaS multi-tenant de gestão, com API e finanças próprias

Repositório privado

Plataforma SaaS multi-tenant com isolamento no banco via Row-Level Security do Postgres. Monorepo NestJS + Flutter, com orbix-api (autenticação, OTP, tokens, finanças) servindo vários produtos como CRM e gestão de oficinas.

  • NestJS
  • Fastify
  • Flutter
  • PostgreSQL
  • RLS
  • Docker

A plataforma

OrbixHub é um SaaS multi-tenant onde vários produtos, como um CRM e uma gestão de oficinas, nascem sobre uma base comum.

Isolamento por tenant

Cada cliente fica isolado no próprio espaço usando Row-Level Security do Postgres, então os dados de um nunca alcançam o do outro.

API central

Uma orbix-api cuida de autenticação, OTP, tokens e finanças e serve todos os produtos, evitando reescrever o mesmo núcleo.

Monorepo

Backend em NestJS e apps em Flutter convivem num monorepo organizado, facil de evoluir em equipe.

Desafio técnico

Servir produtos diferentes a partir de um núcleo só, mantendo segurança, finanças e isolamento de dados por cliente.

Como foi feito

NestJS e Fastify no back, Flutter no mobile, PostgreSQL com RLS e Docker.
